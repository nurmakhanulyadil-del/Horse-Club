
# Argymaq

**Where peace and comfort find perfect harmony**

Argymaq — горный эко-комплекс для отдыха на природе, расположенный в живописных предгорьях недалеко от Алматы. Здесь гармонично сочетаются традиции и комфорт: уютные юрты, настоящая русская сауна, конный клуб и активные развлечения на свежем воздухе.

## 🌐 Сайт

[untitled-dun-kappa.vercel.app](https://untitled-dun-kappa.vercel.app/)

## ✨ О проекте

Сайт создан для гостей, которые хотят отдохнуть от городской суеты и провести время в окружении природы. Многоязычный интерфейс (казахский, русский, английский) делает его доступным для широкой аудитории, а удобная система бронирования через WhatsApp и Instagram упрощает связь с гостями.

## 🏕 Размещение и отдых

Гости могут остановиться в традиционных казахских юртах, оборудованных всем необходимым для комфортного проживания, или насладиться атмосферой настоящей русской бани с зоной отдыха.

## 🐎 Конный клуб

Конный клуб предлагает прогулки верхом и индивидуальные занятия для всех уровней подготовки — от новичков до опытных наездников. Маршруты пролегают через живописные склоны с видом на горы.

## 🎉 Развлечения

К услугам гостей — конные прогулки, традиционные качели алтыбакан, профессиональная фотосессия на природе, караоке под открытым небом, стрельба из лука и настольные игры для всей семьи.

## 🛠 Технологии

- React + Vite

- Tailwind CSS (shadcn/ui)

- Деплой на Vercel
